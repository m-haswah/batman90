# محاضرات batman

تطبيق ويب (PWA) يسجّل المحاضرة (ميكروفون أو صوت Teams)، يرسل الصوت إلى Gemini على مقاطع قصيرة، ويعرض ملخصاً مباشراً وإجابات فورية لأسئلة المحاضر.

## تشغيل محلي
```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```
> بعد حذف حزمتين من package.json شغّل `npm install` مرة واحدة وارفع package-lock.json المحدّث.

## النشر على GitHub Pages
1. أنشئ مستودعاً على GitHub وارفع المشروع إلى الفرع `main`.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. بعد انتهاء الـ workflow يظهر الرابط `https://USERNAME.github.io/REPO/`.

## تثبيته كتطبيق
- أندرويد/كروم: افتح الرابط ← قائمة ⋮ ← «تثبيت التطبيق».
- آيفون/سفاري: مشاركة ← «إضافة إلى الشاشة الرئيسية».
- ويندوز/ماك (Chrome أو Edge): أيقونة التثبيت في شريط العنوان.

## مفتاح Gemini
من https://aistudio.google.com/apikey ثم الصقه في ⚙ الإعدادات داخل التطبيق. يُخزَّن في متصفحك فقط. لا تضعه في الكود.

## Teams
على الكمبيوتر (Chrome/Edge): اختر «محاضرة Teams»، ثم في نافذة المشاركة اختر تبويب Teams (أو الشاشة كاملة في ويندوز) وفعّل مشاركة الصوت. الهاتف لا يسمح بالتقاط صوت التطبيقات، استخدم الميكروفون.
